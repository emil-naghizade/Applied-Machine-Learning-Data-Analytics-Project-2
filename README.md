# Applied-Machine-Learning-Data-Analytics-Project-2



A machine learning project that classifies building energy consumption as **HIGH** or **LOW** and predicts exact kilowatt-hours using multiple classification and regression models. Built with an interactive **Streamlit dashboard** for real-time exploration.

## Dataset

The [Energy Consumption Dataset](https://www.kaggle.com/datasets/govindaramsriram/energy-consumption-dataset) from Kaggle contains **1,100 building-day observations** (1,000 train / 100 test) with 6 features:

| Feature | Type | Range |
|---------|------|-------|
| Building Type | Categorical | Residential / Commercial / Industrial |
| Square Footage | Continuous | 560 – 49,997 sq ft |
| Number of Occupants | Integer | 1 – 99 |
| Appliances Used | Integer | 1 – 49 |
| Average Temperature | Continuous | 10 – 35 °C |
| Day of Week | Binary | Weekday / Weekend |

**Target:** Energy Consumption (1,684 – 6,531 kWh)

## Models

### Classification (Binary: HIGH / LOW)
- **Logistic Regression** — with statsmodels for inference (SE, Z-stats, p-values) and scikit-learn with L2 regularization for prediction
- **Linear Discriminant Analysis (LDA)** — shared covariance, linear decision boundary
- **Quadratic Discriminant Analysis (QDA)** — class-specific covariance, quadratic boundary
- **Gaussian Naïve Bayes** — conditional independence assumption

### Classification (Multi-class: Low / Medium / High)
- **Multinomial Logistic Regression** — softmax extension with One-vs-Rest ROC evaluation

### Regression
- **Linear Regression** (OLS)
- **Poisson Regression** (log-link)

## Results

| Model | Accuracy | Precision | Recall | AUC |
|-------|----------|-----------|--------|-----|
| Logistic Regression | 91% | 1.000 | 0.830 | 0.963 |
| LDA | 91% | 1.000 | 0.830 | 0.960 |
| **QDA** | **91%** | **1.000** | **0.830** | **0.965** |
| Naïve Bayes | 90% | 0.922 | 0.887 | 0.954 |

- All classifiers achieve **AUC > 0.95**
- QDA achieves the highest AUC (0.965)
- Linear Regression: **R² = 0.814**, RMSE = 357.1 kWh
- Square Footage is the dominant predictor (Z = 14.76, p ≈ 0)

## Setup & Usage

### Prerequisites

- Python 3.9+

### Installation

```bash
git clone https://github.com/your-username/energy-consumption-classification.git
cd energy-consumption-classification
pip install -r requirements.txt
```

Or install dependencies manually:

```bash
pip install pandas numpy scikit-learn statsmodels streamlit matplotlib seaborn
```

### Step 1: Train Models

```bash
python main.py
```

This will:
- Load and preprocess the training/test data
- Train all classification and regression models
- Compute metrics, ROC curves, and statistical inference
- Save everything to `models.pkl` and `test_processed.csv`

### Step 2: Launch Dashboard

```bash
streamlit run app.py
```

The app opens at `http://localhost:8501` with 7 interactive tabs:

| Tab | Description |
|-----|-------------|
| **Predictions** | Input building features, get real-time predictions from all models |
| **LR Details** | Coefficient table with SE, Z-statistics, p-values, VIF |
| **Discriminant Analysis** | LDA & QDA ROC curves with adjustable thresholds |
| **Model Comparison** | Side-by-side metrics, ROC overlay, performance charts |
| **Regression** | Actual vs Predicted scatter, residual plots |
| **Confounding** | Correlation heatmap, VIF analysis, confounder detection |
| **Feature Importance** | Coefficient bar charts for LR, LDA, Linear Regression |

## Preprocessing Pipeline

1. **Label Encoding** — Categorical features → integers (fit on train only)
2. **Standard Scaling** — Continuous features → z-scores (fit on train only)
3. **Target Engineering:**
   - Binary: median threshold (4,176 kWh) → HIGH / LOW
   - 3-class: tertile boundaries → Low (< 3,733) / Medium (3,733–4,638) / High (> 4,638)

## Key Findings

- **Square Footage** is the dominant predictor across all models (odds ratio = 41.7×)
- All VIFs ≈ 1.0 → no multicollinearity
- No confounding variables detected
- Average Temperature is the only non-significant feature (p = 0.171)
- Optimal thresholds (found via Youden's J) outperform the default 0.5 cutoff
